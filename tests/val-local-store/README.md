# Integer-origin LOCAL receiving Val

Own MIT regression programs. Harbour is an external executable oracle only.
A direct Val call is a proven F64 producer for the existing ordinary-Linux
integer-origin LOCAL storage hint. Existing tagged storage, metadata, ownership
and runtime parser are unchanged. No general numeric promotion or FOR widening.

check.py: five own programs, twelve argv cases, five Linux modes. 300 fresh
Harbour-exact rc/stdout/stderr triples, 60 strict final allocation-delta-zero
runs, one named rejection (non-integer origin); the former FOR rejection is
now a positive under tests/for-dyn-bound. Includes RHS
catch with Harbour's explicit Break handler, retag/string replacement,
integer metadata before/after, branch not taken and one evaluation.

safety.py: three instrumented lifetime modes, 1000 stores plus 1000 RHS catches
per Work, warmup then net allocation delta zero; five excluded profiles and two
shape rejections. This allocation/error gate is not Harbour error parity.

The Val-only increment advanced intact seconds.prg to the FOR bound limit.
The later for-dyn-bound increment now admits it, without clock byte-parity
closure.
Val's separately documented existing parser deviations remain; these probes
do not establish parity for every numeric string or extend Val's parser.
