# METHOD-shaped expression boundaries: research only

Own sources,pinned Harbour oracle.30overlap/order probes and17plain-expression
boundary observations. No production change,no global priority reversal.
Broad command METHOD <name> [AS <type>] [DECL] must not swallow an adjacent
INLINE or CLASS clause. Harbour's <name> capture is one expression,not the
rest of the statement. The baseline absorbs those words because absent
optional-literal anchors fall back to all remaining tokens. It also swallows
DECL when an earlier optional AS anchor is absent.

All6definitionorders select INLINE/CLASS rules in the reduced family. This
can be achieved by correct complete expression matches,not necessarily by
changing literal-score priority. An isolated broad rule leaves New Other,
INLINE/CLASS/UNKNOWN suffixes unchanged in Harbour. Ordinary arithmetic and
balanced calls are valid expressions;indexing is outside the current bounded
arithmetic grammar and must be treated explicitly,not falsely translated.

The17stringify probes expose the existing optional-literal result guard,so
they are oracle observations,not17passes. Next bounded plan:expression-root
followed by independent optional literal+expression/literal flags,correctly
reconsidering later anchors when earlier optionals are absent. Preserve
repeated-owner limits,source-span provenance and full diagnostics. RealMETHOD
family is larger and must not be enabled merely because reduced cases pass.
No class runtime,ABI/ownership,main,bytes/speed claim.
