## Reproduction and evidence

- Compile each original with `hbc <original> <case>/output.s -I<core>/include`. Compile-only scan limits were 10 seconds wall, 8 seconds CPU, 768 MiB memory and 8 MiB file size.
- Compile-only timings observed: tests about 3.3 s; remaining files about 11.9 s. These timings are not compiler benchmarks.
- Assemble and link admitted cases with `as --64 output.s -o hr.o` and `ld hr.o -o hr`.
- Build the reference with `HB_BUILD_CONTRIBS=no HB_BUILD_DYN=no HB_BUILD_SHARED=no make -j4`.
- Compare stdout bytes, stderr bytes and exitcode. Do not count a timeout as normal termination.
